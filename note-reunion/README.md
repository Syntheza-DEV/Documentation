# Notes de Réunion

Ce dossier contient l'ensemble des comptes-rendus de réunions organisés par mois.

## 📋 Structure

```
note-reunion/
├── README.md
├── 2025-12 Décembre/
├── 2026-01 Janvier/
├── 2026-02 Février/
├── 2026-03 Mars/
├── 2026-04 Avril/
├── 2026-05 Mai/
└── 2026-06 Juin/
```

## 📝 Nomenclature

Les fichiers de notes doivent suivre le format suivant :

```
YYYY-MM-DD_reunion_note.md
```

### Exemples
- `2025-12-18_reunion_note.md`
- `2025-12-20_reunion_note.md`
- `2025-12-22_reunion_note.md`

## 📄 Template de Note

Chaque note de réunion doit suivre la structure suivante :

```markdown
# [Type] - [Sujet]

**Date** : JJ/MM/YYYY
**Heure** : HH:MM - HH:MM
**Participants** : Nom1, Nom2, Nom3
**Animateur** : Nom
**Rédacteur** : Nom

## Contexte

Brève description du contexte et de l'objectif de la réunion.

## Revue des objectifs

- ✅ Objectif 1 de la réunion précédente : Statut
- ✅ Objectif 2 de la réunion précédente : Statut
- ⏳ Objectif 3 de la réunion précédente : Statut

## Ordre du jour

1. Point 1
2. Point 2
3. Point 3

## Discussions & Décisions

### [Sujet 1]
- **Discussion** : Résumé des échanges
- **Décision** : Décision prise
- **Responsable** : @nom
- **Échéance** : JJ/MM/YYYY

### [Sujet 2]
- **Discussion** : ...
- **Décision** : ...

## Actions à mener

| Action | Responsable | Échéance | Statut |
|--------|-------------|----------|--------|
| Action 1 | @nom | JJ/MM/YYYY | 🔄 En cours |
| Action 2 | @nom | JJ/MM/YYYY | ⏳ À faire |

## Points en suspens

- Point non résolu 1
- Point non résolu 2

## Objectifs prochaine réunion

1. Objectif 1 à atteindre
2. Objectif 2 à atteindre
3. Objectif 3 à atteindre

## Prochaine réunion

**Date prévue** : JJ/MM/YYYY
**Sujets** : Liste des sujets à aborder
```

## 🎯 Bonnes pratiques

1. **Créer la note dans le dossier du mois correspondant**
2. **Rédiger la note dans les 24h suivant la réunion**
3. **Utiliser des liens vers les issues/tickets concernés**
4. **Mentionner les participants avec @**
5. **Être concis et factuel**
6. **Mettre en évidence les décisions importantes**
7. **Définir des responsables et échéances clairs**

## 🔍 Retrouver une note

- Par date : Naviguer dans le dossier du mois
- Par sujet : Utiliser la recherche de fichier avec le sujet
- Par type : Rechercher le préfixe `_<type>_` dans les noms de fichiers
